# Dataset

Place the trusted `input_data.pkl` provided with this project in `data/` (or the notebook directory). It is approximately 883 MB and is excluded from Git.

The supplied dictionary contains `texts`, `years`, `months`, `X_bow` and `labels`: 11,000 news entries, 10,000 Bag-of-Words features and 18 labels. Category names and a BoW vocabulary mapping are not provided.

Original dataset download location: https://frasca.di.unimi.it/MLDNN/input_data.zip . Availability is not required by the notebook and redistribution rights have not been established. Obtain the file from its original source; this repository does not redistribute it. Its SHA-256 checksum is recorded in `reports/run_metadata.json`.
